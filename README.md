# Manu.html - Chiikawas Tribute Page

Una página web profesional y hermosa dedicada a celebrar la serie de anime/manga **Chiikawas**.

## 📖 Descripción del Proyecto

Este proyecto es una página web interactiva que presenta la historia, el contexto cultural y los personajes principales de Chiikawas. La página está diseñada para ser visualmente atractiva, responsive y fácil de navegar.

## ✨ Características

- **Diseño Profesional**: Interfaz moderna y atractiva con degradados personalizados
- **Historia Completa**: Secciones detalladas sobre los orígenes, desarrollo e impacto cultural de Chiikawas
- **Galería de Personajes**: Presentación interactiva de los personajes principales
- **Responsive Design**: Optimizado para desktop, tablet y móvil
- **Animaciones Suaves**: Transiciones y efectos visuales profesionales
- **Navegación Intuitiva**: Barra de navegación sticky para fácil acceso

## 🎨 Estructura de la Página

### Secciones Principales

1. **Navbar**: Navegación principal con links a todas las secciones
2. **Hero Section**: Sección de bienvenida con llamada a la acción
3. **Historia**: Cuatro tarjetas que cubren:
   - Los Orígenes
   - Concepto y Desarrollo
   - Lanzamiento y Recepción
   - Impacto Cultural
4. **Personajes**: Galería de personajes principales
5. **Footer**: Información de contacto y créditos

## 🚀 Cómo Usar

1. Abre el archivo `index.html` en tu navegador web
2. Navega por las diferentes secciones usando la barra de navegación
3. Explora la historia y los personajes de Chiikawas
4. Disfruta de las animaciones y efectos visuales
